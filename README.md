# 차샘 운전교실 - PC 수강생 실력 체크리스트

수강생을 등록하고, 수업이 끝날 때마다 회차별 점수를 입력하면 **Google
스프레드시트**에 이력으로 쌓이는 도구입니다. Google Apps Script로 만들어서
별도 서버 없이 구글 계정만 있으면 됩니다.

화면은 두 개의 탭으로 나뉩니다.

- **수강생 관리**: 전체 수강생 명부 - 연락처/등록일/총 수업횟수/최근 점수/
  이전 점수/향상도/현재 레벨/강사 메모를 한눈에 보고, 새 수강생을 등록합니다.
- **회차별 평가**: 수강생 한 명을 골라 이번 회차(수업) 점수를 10개 항목에
  입력해 저장하고, 그동안의 수업 이력을 표로 확인합니다.

웹 앱 화면 상단의 "사용방법 보기"를 펼치면 아래와 같은 8단계 안내와 점수
기준 범례가 그대로 나옵니다.

## 점수 기준

| 점수 | 평가 | 색상 |
|---|---|---|
| 90~100 | 능숙 | 초록 |
| 75~89 | 가능 | 청록 |
| 60~74 | 연습 필요 | 노랑 |
| 0~59 | 집중 연습 | 빨강 |

이 기준은 `Code.gs`의 `levelFromScore_` 함수와 `JavaScript.html`의
`tierClass`/`tierLabel` 함수 두 군데에 정의돼 있습니다. 기준을 바꾸려면
**이 세 곳을 모두 같은 경계값으로** 맞춰야 합니다. 개별 항목 점수, 종합점수,
수강생의 "현재 레벨" 모두 이 기준 하나로 계산됩니다.

`setup()`을 실행하면 Sessions 시트의 점수 열(항목 10개 + 종합점수)에도
같은 기준으로 **조건부 서식(배경색)**이 자동으로 걸립니다 - 스프레드시트를
직접 열어도 점수 셀 색으로 실력 수준을 바로 확인할 수 있습니다.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `Code.gs` | 서버 코드 - 스프레드시트 읽기/쓰기, 점수·레벨·향상도 계산 |
| `index.html` | 화면 뼈대 (탭 2개) |
| `Stylesheet.html` | 디자인(CSS) |
| `JavaScript.html` | 화면 동작 (입력 저장, 탭 전환, 표 렌더링 등) |

## 설치 방법 (한 번만 하면 됩니다)

1. **새 스프레드시트 만들기**
   [sheets.new](https://sheets.new) 로 접속해 새 스프레드시트를 만들고,
   이름을 "운전 실력 진단 DB" 처럼 알아보기 쉽게 바꿔 주세요.

2. **Apps Script 열기**
   메뉴에서 `확장 프로그램 → Apps Script` 를 클릭합니다.

3. **Code.gs 붙여넣기**
   기본으로 열려 있는 `Code.gs`의 내용을 모두 지우고, 이 폴더의
   [`Code.gs`](Code.gs) 내용을 그대로 붙여넣습니다.

4. **HTML 파일 3개 추가**
   왼쪽 파일 목록의 `+` 버튼 → `HTML` 을 눌러 아래 이름으로 3개를 만듭니다.
   (Apps Script가 자동으로 `.html`을 붙이므로 이름만 정확히 입력하면 됩니다.)
   - `index` → [`index.html`](index.html) 내용 붙여넣기
   - `Stylesheet` → [`Stylesheet.html`](Stylesheet.html) 내용 붙여넣기
   - `JavaScript` → [`JavaScript.html`](JavaScript.html) 내용 붙여넣기

5. **초기 설정 실행**
   상단 함수 선택 드롭다운에서 `setup` 을 고르고 ▶ 실행 버튼을 누릅니다.
   처음 실행하면 "권한 검토" 창이 뜹니다 → 본인 계정 선택 →
   "고급" → "(프로젝트 이름)(으)로 이동" → "허용" 순서로 승인해 주세요.
   (직접 만든 스크립트라 안전 경고가 뜨는 것이며, 다른 사람 코드가 아니라
   본인이 붙여넣은 코드에 대한 권한 요청입니다.)

   실행 후 스프레드시트로 돌아가면 `Students`, `Sessions` 시트가 새로 생기고
   데모 수강생 "이석재"의 1회차 점수가 채워져 있는지 확인하세요.

6. **웹 앱으로 배포**
   Apps Script 화면 오른쪽 위 `배포 → 새 배포` 클릭 →
   톱니바퀴 아이콘 → `웹 앱` 선택 →
   - 다음으로 실행: **나**
   - 액세스 권한: 나만 쓸 거면 **나만**, 다른 강사와 같이 쓸 거면
     **전체**(로그인 없이도 링크로 접속 가능) 중 선택
   → `배포` 클릭 → 액세스 승인 → 발급된 **웹 앱 URL**을 복사합니다.

7. 그 URL로 접속하면 화면이 뜹니다. **수강생 관리** 탭에서 학생을 등록하고,
   **회차별 평가** 탭에서 그 학생을 고른 뒤 오늘 수업 점수를 입력해 "이번
   회차 저장"을 누르면 스프레드시트에 한 줄이 쌓입니다.

## 코드를 수정했을 때

이 저장소(`estudy77/chasaem-app`)는 GitHub Actions로 자동 배포가 설정되어
있습니다. `master` 브랜치에 push하면(GitHub 웹 편집기에서 고쳐도, 로컬에서
`git push`해도 상관없음) 자동으로:

1. `clasp push`로 Apps Script 프로젝트에 코드 반영
2. 기존 웹 앱 배포에 새 버전 배포

가 실행됩니다 (`.github/workflows/deploy.yml`). Apps Script 편집기나 clasp를
직접 쓸 필요 없이, **GitHub에 push만 하면 끝**입니다. 진행 상황은
https://github.com/estudy77/chasaem-app/actions 에서 확인할 수 있습니다.

## 데이터 구조

- **Students 시트**: `StudentId, Name, Contact, RegisteredDate, Memo`
  - 수강생 명부. 회차/점수는 여기 없고 전부 Sessions 시트에서 계산합니다.
- **Sessions 시트**: `Date, StudentName, SessionNo, 기본조작 ~ 위험대처(10개),
  TotalScore, PrevScore, StudentId, SessionId, CreatedAt`
  - 수업마다 한 행씩 **추가만 되는 이력**입니다 (기존 행은 고치지 않음).
  - `TotalScore`는 그 회차 10개 항목의 평균, `PrevScore`는 저장 시점의 바로
    이전 회차 점수를 그대로 기록해 둔 값입니다.
  - 항목 10개(기본조작~위험대처)는 `Code.gs` 상단의 `ITEMS` 배열이 기준입니다.
    항목을 추가/변경하려면 이 배열과 `JavaScript.html`의 `ITEM_META` 배열
    (수업 이력 표 제목을 그리는 데 씀) 둘 다 같은 순서로 맞춰 주세요.
  - 앞쪽 6개 열(수업일~이전점수)이 사람이 읽는 열이고, 뒤쪽 `StudentId` /
    `SessionId` / `CreatedAt`은 조회용 기술 열입니다.

수강생 관리 탭의 **최근 점수 / 이전 점수 / 향상도 / 현재 레벨**과 회차별
평가 탭의 요약은 모두 Sessions의 마지막 두 회차를 비교해서 매번 다시
계산되는 값이며, 별도로 저장되지 않습니다.

## 회차 관리

- 회차 번호는 학생별로 자동 증가합니다 (직접 입력하지 않아도 됩니다).
- 잘못 입력했다면 회차별 평가 탭의 **"마지막 회차 삭제"**로 가장 최근 회차만
  되돌릴 수 있습니다. 그 이전 회차들은 그대로 보존됩니다.
- 두 시트 모두 일반 스프레드시트 탭이라, 필요하면 직접 열어서 값을 확인하거나
  수동으로 고칠 수도 있습니다.

## 참고

- 여러 사람이 동시에 저장해도 `LockService`로 저장 충돌을 막습니다.
- 수강생 관리 탭의 연락처/등록일/강사 메모는 입력 후 포커스를 벗어나면
  (변경이 있을 때만) 자동 저장됩니다.
- 스프레드시트 이름이나 위치를 바꿔도 상관없습니다. 이 스크립트는 항상
  "자신이 붙어 있는 스프레드시트"를 사용합니다(컨테이너 바인딩 방식).
